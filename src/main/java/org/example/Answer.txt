Questions:
- What happens if users choose "Cancel"?
- How to customize the options to users, e.g. only two options: "Yes" and "No", OR "I do" and "I don't" (Suggestion: Use Javadocs or using Eclipse/Netbean IDE help)?

Answers:
1. What happens if users choose "Cancel"?
- Clicking "Cancel" makes JOptionPane.showConfirmDialog return JOptionPane.CANCEL_OPTION (value 2).
- Closing the dialog window via the "X" button returns JOptionPane.CLOSED_OPTION (value -1).
- The program evaluates the choice using: (option == JOptionPane.YES_OPTION ? "Yes" : "No").
- Because JOptionPane.YES_OPTION is 0, both 2 (Cancel) and -1 (Closed) evaluate to false, causing the program to incorrectly display: "You've chosen: No".

2. How to customize the options to users:
- To show only two options ("Yes" and "No"):
  Use JOptionPane.showConfirmDialog with JOptionPane.YES_NO_OPTION:

  int user_option = JOptionPane.showConfirmDialog(
      null,
      "Do you want to change to the first class ticket?",
      "Select an Option",
      JOptionPane.YES_NO_OPTION
  );

- To customize button labels (e.g., "I do" and "I don't"):
  Use JOptionPane.showOptionDialog with a custom Object array passed to the options parameter:

  String[] custom_options = {"I do", "I don't"};
  int user_choice = JOptionPane.showOptionDialog(
      null,
      "Do you want to change to the first class ticket?",
      "Select an Option",
      JOptionPane.YES_NO_OPTION,
      JOptionPane.QUESTION_MESSAGE,
      null,
      custom_options,
      custom_options[0]
  );
